## 검증 결과와 범위

- `flutter test --no-pub --reporter expanded`: **31/31 통과**. [원문](tests-after.txt)
- `flutter build apk --debug --no-pub --target-platform android-arm64`: **성공**, 최종 코드 `3961189` 기준 22.2초. 산출물 `build/app/outputs/flutter-apk/app-debug.apk`. 설치 테스트용 debug APK이며 스토어 업로드용 서명 release AAB가 아니다. [로그](android-build-after.txt)
- `flutter analyze --no-pub`: **error 0 / warning 0 / info 43**. info 때문에 종료 코드 1. 남은 항목은 파일명·불필요 구문·deprecated Flutter API 등이다. [원문](analyze-after.txt)
- 실제 서버: 로그인, 토큰 갱신, 프로필, 팔로우, 서재 3개 상태, 도서, 인물/카테고리, DNA 질문/결과, 알림/설정, 타이머 설정/오늘·전체 통계가 HTTP 200. 진행 중 타이머 조회 404는 없는 세션으로 처리한다.
- 실제 계정에서는 로그인·갱신 및 읽기만 수행했다. 서재 추가/삭제·프로필 변경·팔로우 변경·타이머 생성·회원 탈퇴는 실행하지 않았다. 계정 정보와 토큰은 보고서·테스트에 저장하지 않았다.
- 자동 테스트는 fake API/플랫폼 및 로컬 HTTP 서버를 이용한다. 실기기 화면 순회, 실제 FCM 배달, 카카오·이메일 인증 완료를 대신하지 않는다.

## 출시 전 남은 항목

1. **업로드 서명 키 복구:** 설정은 `android/key.jks`를 가리키지만 파일이 없다. 존재하는 `android/upload-keystore.jks`도 현재 설정의 암호로 열리지 않았다. 기존 Play 등록 업로드 키의 올바른 파일/경로/암호가 필요하다. 새 키 생성·암호 추측·스토어 배포는 하지 않았다.
2. **실기기 검증:** 로그인 유지, 서재 생성/수정/삭제, 푸시 허용/거부와 종료 상태 클릭, 타이머 잠금·백그라운드·오프라인·강제 종료, 이메일/카카오 인증을 확인해야 한다.
3. **대상 브랜치:** `origin/feat/celebrity-image-copyright`는 별도 기능 브랜치여서 미병합이다. 그 브랜치의 `assets/images/person.png` 누락은 본 main 수정 범위에 포함하지 않았다.
4. **Play Console:** versionCode 2 재사용 여부 및 업로드 키 일치는 미검증이다.
