# Android 요청 사항 검증 체크리스트

대상: WhoReads Android. 연결 기기: Galaxy S9 SM-G960N, Android 10.
실제 USB 연결 기기의 화면을 캡처해 확인하고 버튼을 조작했다. Galaxy S23 실물은 연결되어 있지 않아 검사하지 않았다.

- [x] 회원가입 후 DNA 결과 → 추천도서에서 인증 세션 유지: 자동 회귀 검사 통과.
  - 가입 직후 access/refresh token을 저장하는 기존 처리를 `signup_recommendations_flow_test.dart`로 확인했다.
  - 사용자 요청에 따라 신규 이메일 실가입은 생략했다. 실기기에서는 기존 계정으로 카카오 로그인 → DNA 5문항 완료 → 스티븐 킹 추천도서 목록 → Shaker 상세까지 로그인 화면으로 되돌아가지 않았다.
- [x] 책 상세의 읽는 중 독서량 숫자 크기 통일: 실기기·자동 검사 통과.
  - 퍼센트·페이지 수를 15로 맞추고 편집 입력 크기와 일치시켰다.
  - 팩트풀니스 25/484p(5%)를 저장하고 상세를 다시 열어 서버 저장 결과와 동일한 글자 크기를 확인했다.
  - 실기기에서 발견한 추가 직후 전체 페이지 수가 0p로 보이는 문제도 수정했다. 서재 추가 후 상세 정보를 다시 읽어 484p를 즉시 표시한다. 서버 규칙에 맞게 1 미만의 입력은 요청 전에 안내한다.
- [x] 인물 추천 목록의 책 → 실제 book_id의 상세 이동: 실기기·자동 검사 통과.
  - 스티븐 킹 → Shaker, 페이커 → 팩트풀니스로 확인했다. 자동 검사는 추천사 ID와 책 ID가 다른 사례를 검증한다.
  - 목록의 추가 버튼은 상세 이동과 별도로 작동하고, 상세에서 돌아오면 추가·삭제 상태를 갱신한다.
- [x] Android 세로 고정: 실기기 확인.
  - 기존 manifest/Flutter 설정을 유지했다. 기기 가로 방향 요청 시 앱은 `SCREEN_ORIENTATION_PORTRAIT`, 화면은 1080×2220 세로로 유지됐다.
- [x] 프로필 DNA 결과 다시보기·재테스트: 실기기·자동 검사 통과.
  - 결과가 없을 때 소개 → 첫 테스트, 결과가 있을 때 화살표 → 저장된 결과로 이동한다.
  - 다시 테스트하기 → Android 뒤로 가기로 취소하면 기존 결과를 유지한다.
  - 재테스트 완료 후 인물이 스티븐 킹 → 앤서니 라빈스로 바뀌고 프로필 문구도 최신 결과로 갱신되는 것을 확인했다.
  - 긴 결과와 작은 화면에서도 버튼에 접근할 수 있도록 결과 본문을 스크롤할 수 있게 했다. 프로필 긴 메뉴와 테스트 소개 제목의 가로 넘침도 보완했다.
- [x] 로그인 도움말 두 줄 분리: 실기기·자동 검사 통과.
  - 비밀번호 안내/재설정 링크와 계정 안내/찾기 링크가 각각 별도 줄에 표시된다. 두 링크를 직접 눌러 해당 화면으로 이동했다.
  - 320/360/384 논리 너비 × 글자 확대 1.0/1.3 총 6개 레이아웃 조합을 검사했다. 이는 Galaxy S23 실물 검증을 의미하지 않는다.

## 검증 기록

- Android 요청 회귀 검사 10개 통과. 전체 프로젝트 Flutter 검사 83개 통과.
- 변경 파일 분석: 오류·경고 0개, 기존 스타일/사용 중단 안내 16개.
- 최종 debug APK 빌드·설치 성공. APK 환경 설정 검사 통과(BASE_URL만 포함, 값은 출력하지 않음).
- 로그인 도움말 검증 후 카카오 재로그인 성공. 검증용으로 추가한 도서는 모두 삭제했다.
- 원래 Android Studio 프로젝트에도 요청 관련 파일을 반영했다. 기존 iOS/타이머 작업은 보존했다.
- 이번 검증본은 연결 기기에 설치한 debug 앱이며 Google Play에 새 버전을 제출하지 않았다.
