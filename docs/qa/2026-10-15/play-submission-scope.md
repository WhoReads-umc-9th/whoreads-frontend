# 비공개 테스트 자동 배포 범위 검증

2026-10-15 KST. 앱은 `com.whoreads.mobile`, 자동 배포 대상은 기존 Alpha 비공개 테스트뿐이다.

## 기존 공개 테스트 초안 기록

공개 테스트 트랙은 비활성이었고 출시된 버전은 없었다. 미제출 국가 설정은 다음 두 가지였다.

- 프로덕션 국가 설정과 동기화 해제
- 대한민국(KR) 1개 국가 추가

원래 화면은 `open-test-draft-before.png`, 상세 접근성 기록은 `open-test-country-draft-before.txt`에 남겼다.
향후 사용자가 공개 테스트를 요청하면 국가/지역 탭에서 동기화를 해제한 뒤 대한민국을 선택해 재구성할 수 있다. 공개 테스트 버전은 별도로 필요하다.

## 발견 및 수정

처음 API 제출한 `1.0.3+4`는 API 요청에서 Alpha만 수정했지만 기존 공개 테스트의 두 국가 설정도 검토 목록에 포함됐다. Console의 **나중을 위해 저장**은 API commit 범위를 분리하는 장치로 사용할 수 없었다.

이 제출 전체를 검토에서 취소해 미제출 상태로 되돌렸고, 공개 테스트의 두 국가 설정은 기록 후 원래의 프로덕션 동기화 상태로 복구했다. 프로덕션 국가 설정이 비어 있음을 API로 확인했으므로 공개 테스트 대상 국가는 0개다. 공개 테스트 버전은 만들거나 배포하지 않았다.

재발 방지로 prepare와 publish에서 Alpha 이외 트랙에 버전이나 국가 설정이 있으면 업로드 전에 차단한다. 공개 테스트의 KR 국가 초안이 있을 때 실제 업로드/commit이 호출되지 않는 회귀 검사를 추가했다.

API 제출 성공과 Google 심사 승인·테스터 제공 완료는 별도로 확인한다.
